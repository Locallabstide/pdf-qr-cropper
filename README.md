# PDF 二维码提取工具

从 PDF 中批量提取二维码，自动裁成正方形图片并打包为 ZIP。

**纯前端单文件 · 完全离线 · 零上传**

---

## 这是什么

一份 PDF 里排了几十个二维码，需要一个个抠出来变成独立图片？手动截图裁剪命名，一晚上就没了。

这个工具：把 PDF 丢进去 → 自动找出所有二维码 → 按码眼定位裁成正方形 → 打包 ZIP 下载。全程几秒钟，全程在你的浏览器里完成。

---

## 功能特性

| 特性 | 说明 |
|------|------|
| **码眼精准定位** | 基于 ZXing 的定位图案识别，裁切不歪不斜，不依赖固定间距假设 |
| **三尺度自适应检测** | 1x → 2x → 按需 3x，大码一遍过，小码自动升采样救援 |
| **Web Worker 多核并行** | 检测按 CPU 核数自动开多线程池，UI 不冻结 |
| **分辨率解耦** | 检测用 1800px 降采样图（快），裁切用原始高分辨率图（清楚） |
| **中文文件名** | ZIP 使用 UTF-8 flag，中文名不乱码，重名自动避让 |
| **零依赖 ZIP** | 自实现打包器，不引入 JSZip；Blob 零拷贝拼接 |
| **崩溃自愈** | Worker 异常终止自动替补并回收队列，不会永久卡死 |

## 快速开始

1. 双击 `pdf-qr-cropper-offline.html`，用 **Chrome** 或 **Edge** 打开
2. 把 PDF 文件拖进浏览器窗口任意位置
3. 点「开始检测并裁切」
4. 点「打包导出 ZIP」

下载得到 `你的PDF文件名-crops.zip`，解压就是一张张正方形 JPG。

> 不需要安装、不需要联网、不需要起服务器。这是一个单独的 HTML 文件，可以放 U 盘、可以发邮件。

## 工作原理

```
PDF 文件
   ↓  pdf.js 渲染（默认 300 DPI）
全尺寸 Canvas
   ↓  降采样至最长边 ≤ 1800px
检测图
   ↓  zxing-wasm 在 Worker 池中识别码眼（三尺度自适应）
码眼坐标
   ↓  坐标回映射到原始 Canvas
   ↓  按码眼外接方框裁正方形（四周留 6% 白边）
正方形 JPG
   ↓  自实现 ZIP 打包器
ZIP 下载
```

### 三尺度检测策略

| 轮次 | 做法 | 继续条件 |
|------|------|----------|
| 第 1 轮 | 原尺寸扫描 | 总是执行 |
| 第 2 轮 | 放大 2 倍扫描 | 未跳过 2x 且像素数在限制内 |
| 第 3 轮 | 放大 3 倍扫描 | 2x 找到新码 **或** 1x 全空（救援分支） |

典型的大码文档只需 1 轮即可完成，比无条件三尺度扫描快约 3 倍。

## 使用参数

| 参数 | 默认 | 说明 |
|------|------|------|
| 渲染 DPI | 300 | 200 更快 / 400 更精细。决定裁切清晰度 |
| 起始编号 | 1 | 输出文件从 `001.jpg` 开始连续编号 |
| 并发页数 | 按 CPU 核数（2–6） | 同时处理几页 |

## 隐私说明

- **零网络请求**。PDF 和图片只在浏览器内存中处理，关掉页面即消失。
- 识别引擎（pdf.js + zxing-wasm）完全内嵌在 HTML 文件里，拔网线也能用。
- 想验证：打开开发者工具（F12）→ Network 面板 → 清空 → 完整跑一遍 → 看不到任何对外请求。

---

## 已知限制

- 只识别 QR Code，不支持一维条形码及其它码制
- 单次只能处理一个 PDF
- 加密 / 有密码的 PDF 无法处理
- 不消费二维码的解码内容（仅裁切图片）

详细说明见 [开发者手册](开发者手册.html) 第 18 章。
